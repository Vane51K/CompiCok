Developer Documentation

📁 File Structure

CompiCok/
├── index.html   ← Structure & markup
├── style.css    ← All visual styling
└── script.js    ← Logic, simulation, interactivity

⚙️ index.html

Contains the full semantic HTML layout: header navigation, translation panels, compiler analytics tabs, and the footer. All IDs and classes are hooked into script.js and style.css.

🎨 style.css

Uses CSS custom properties (--color-*) for the theme. Includes animations (neon glow, spinner, stagger reveals), responsive media queries, and grid/flex layouts.

🧠 script.js

Simulates a lexical analyzer (tokenizer), symbol table builder, error detector, AST renderer, and semantic analyzer — all in plain JavaScript. Functions map directly to UI actions.

🐍 Future Flask Integration

// In script.js, replace simulateTranslation() with:
async function translate() {
  const res = await fetch('http://localhost:5000/translate', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ text: inputText, lang: sourceLang })
  });
  const data = await res.json();
  renderOutput(data.translation);
  renderTokens(data.tokens);
  renderErrors(data.errors);
}

Your Flask backend should expose POST /translate returning {translation, tokens, symbols, errors, ast}.
